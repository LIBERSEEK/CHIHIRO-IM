# Outreach module

The `outreach` module implements the product feature displayed as “营销获客”.

- `components/`: workbench, task composer, login, library, and preview UI.
- `stores/`: campaign preparation and task-card state.
- `domain/`: campaign planning, templates, and layout rules.
- `api/`: client for the `/api/runtime/outreach/*` contract.

Frontend work should import from `modules/outreach`.
